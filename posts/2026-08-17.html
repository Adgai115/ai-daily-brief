Qwen Code v0.21.12-preview.5发布：0.21.12继续进入公开预览验证阶段

A 级Qwen Code / AI编程T0｜代码/CLI发布官方确认｜GitHub Release

重点事件：8月16日00:48 UTC，Qwen Code官方GitHub发布v0.21.12-preview.5，并提供macOS、Linux、Windows构建产物及SHA256校验文件。该版本明确标记为prerelease，属于0.21.12稳定版之前的公开预览阶段。

为什么值得关注：对企业和开发团队而言，预览版的价值不在于“版本号更新”本身，而在于可以提前验证即将进入稳定版的CLI行为、兼容性和工作流变化。它与此前0.21.11稳定版属于新的版本阶段，不应按同一事件去重。

落地建议：生产环境继续固定稳定版；有回归测试环境的团队可安装preview通道验证现有MCP、Hooks、Skills、自动化脚本和Windows/Linux构建兼容性，并在稳定版发布前记录差异。

新增进展：DeepSeek V4新价格进入实际生效日，Pro峰值输出价升至3.96美元/百万Token

A 级DeepSeek / API定价T0｜价格规则生效高可信｜已公布规则进入生效日

重点事件：DeepSeek此前公布的新计价规则自8月16日起进入实际生效阶段。V4 Pro峰值输出价由每百万Token 0.87美元提高至3.96美元，非峰值为1.98美元；V4 Flash峰值输出价为1.32美元、非峰值0.66美元。本卡只记录“从公布到实际生效”的新增阶段，不重复此前价格公告主体。

为什么值得关注：这意味着依赖DeepSeek API的生产应用现在需要按新价格重新计算真实成本，尤其是高输出Token、Agent循环、多轮代码生成和高峰时段调用。价格变化已经从预算预期变成实际账单变量。

落地建议：立即按峰值/非峰值分别重算单任务成本，检查路由器是否支持按时间段切换模型；对Agent任务增加最大输出、循环次数和缓存策略。若业务对延迟不敏感，可评估把批处理任务迁移到非峰值窗口。

开放权重竞争开始反向强化算力需求逻辑：低模型成本未必意味着基础设施需求下降

B 级开放权重 / 算力T0｜产业判断首次确认高可信｜WSJ产业分析

重点事件：8月16日，Wall Street Journal集中梳理中国开放权重模型对闭源模型厂商的价格压力，并指出更低模型成本可能通过更高使用量继续推升数据中心、芯片和云服务需求。报道特别将Kimi K3等开放权重模型与Nvidia、Cerebras及云基础设施需求联系起来。

为什么值得关注：市场此前常把“模型价格下降”直接等同于“算力价值下降”，但企业采用开放权重模型后仍需要推理硬件、云资源、部署工具和运维体系。成本下降反而可能扩大可部署场景，形成类似杰文斯悖论的需求扩张。

落地建议：做AI基础设施、私有化部署或企业Agent方案时，不要只跟踪单模型Token价格；应同步跟踪调用量、并发、上下文长度、私有部署渗透率和推理硬件利用率。商业模型可从“卖模型能力”进一步转向“部署、路由、推理优化和算力治理”。
