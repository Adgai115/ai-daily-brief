欧盟要求 Google 向 AI 助手开放 Android 能力与搜索优化数据

S 级平台开放与监管24小时高可信｜监管决定与权威媒体确认

重点事件：欧盟委员会于 7 月 16 日明确 Google 履行《数字市场法》的具体要求：竞争性 AI 助手将可接入 Android 的 11 项关键能力，包括语音唤醒后执行叫车、地点搜索等操作；相关 Android 能力计划于 2027 年 7 月落地。Google 还须从 2027 年 1 月起，以匿名化方式向具备搜索功能的 AI 服务共享其用于优化搜索的数据，并可先进行隐私与网络安全审查。

为什么值得关注：AI 助手竞争将从“模型回答质量”进入“操作系统能力和搜索训练信号是否可获得”的平台层竞争。对 OpenAI 等第三方而言，这是进入 Android 默认入口与搜索反馈闭环的实质机会；对 Google 而言，开放义务也会增加数据治理和安全审查成本。

落地建议：面向欧洲用户的 AI 产品应提前设计 Android 深度集成、数据最小化和安全认证方案；搜索型产品要评估共享数据的定价、匿名化限制与可训练价值。企业移动端采购也应避免把关键流程锁定在单一助手或单一系统入口。

上市公司公告首次给出 DeepSeek 融资定价证据，交易推算估值约 518 亿美元

S 级国产模型与资本24小时高可信｜交易所公告与权威媒体核验

重点事件：7 月 16 日披露的中国上市公司公告显示，一只基金以 29 亿元人民币获得 DeepSeek 间接 0.8265% 股权，对应交易推算估值约 3508.8 亿元人民币（约 518.2 亿美元）。另一家上市公司披露的间接持股价格基本形成交叉验证。该数字是交易隐含股权估值，并非 DeepSeek 正式公布的轮次估值；公告同时提供了其首次外部融资完成的罕见公开证据。

为什么值得关注：DeepSeek 过去主要依赖创始人旗下量化基金支持，如今外部资本定价被公开文件验证，说明国产前沿模型竞争已从低成本技术叙事进入长期算力、人才和资本市场协同阶段。未来 API 价格与开放策略可能更受扩容、融资和上市节奏影响。

落地建议：使用 DeepSeek 承载关键业务的企业应把供应商资本结构、算力扩容和上市前治理变化纳入连续性评估；同时保留多模型路由、评测资产与可迁移提示词。投资与合作判断应区分“交易推算估值”和“公司正式融资估值”。

Google AI Mode 开始连接 Instacart、Canva 与 YouTube Music 执行动作

A 级AI Agent 与应用连接24小时高可信｜官方帮助页确认

重点事件：Google 于 7 月 16 日公开的产品说明显示，Search 的 AI Mode 已支持连接第三方应用：可根据食谱创建 Instacart 购物车、在 Canva 生成设计草稿、在 YouTube Music 创建播放列表。当前范围为美国、英语、已登录 Google 账号，具体可用性受设备、地区和账号影响；结账、下载或后续编辑仍会跳转到合作应用完成。

为什么值得关注：搜索入口正在由“给答案”升级为“发起跨应用操作”。这会把账户绑定、权限同意、历史记录和第三方交易责任直接带入 AI 搜索，也意味着搜索流量可能进一步转化为可执行任务和商业分发。

落地建议：企业接入此类入口时，应为“生成建议、创建草稿、加入购物车、最终付款”设置分级权限，避免模型直接跨越高风险确认点；同时记录账号绑定、数据共享范围和撤销路径。面向美国以外用户的产品不要假设功能已普遍开放。

华为 Atlas 950 SuperPoD 将在 WAIC 首次公开亮相，国产模型与算力栈进一步耦合

A 级中文 AI 生态与算力24小时高可信｜权威媒体核验

重点事件：7 月 16 日确认的信息显示，华为将在 7 月 17—20 日上海世界人工智能大会期间首次公开展示 Atlas 950 SuperPoD。该系统通过高速互连把数千颗昇腾处理器组成统一训练与推理集群；DeepSeek 最新 V4 已适配在昇腾集群上完整运行，壁仞与沐曦也被报道将展示各自的“超节点”方案。

为什么值得关注：国产 AI 竞争正在从单颗芯片性能转向模型、互连、集群调度和软件栈的系统级协同。对受先进芯片供应限制影响的企业而言，能否稳定迁移训练与推理任务，比单次峰值算力更有现实价值。

落地建议：准备采用国产算力的团队应使用真实业务任务验证算子兼容、分布式训练稳定性、推理吞吐、故障恢复与模型迁移成本；合同中应明确集群交付时间、软件栈版本、适配责任和备用容量，不要仅依据展会峰值指标采购。

DoorDash 开放 dd-cli 限量测试，让 AI Agent 直接搜索门店并进入结账流程

A 级Agentic Commerce近7天补充中高可信｜官方高管声明经媒体核验

重点事件：DoorDash 联合创始人兼 CTO Andy Fang 于 7 月 15 日宣布 dd-cli 限量测试。该命令行工具允许 AI Agent 搜索门店、比较优惠并进入结账流程，当前仅面向美国和加拿大的 macOS 开发者通过候补名单开放。与传统网页自动化不同，它把真实消费服务直接暴露为面向 Agent 的操作入口。

为什么值得关注：AI Agent 正从办公与编码工具进入真实交易。订单金额、地址、支付方式和商品选择一旦由 Agent 操作，错误执行、诱导提示、账号盗用和责任归属都会变成直接经济风险。

落地建议：企业设计 Agent 交易能力时，应强制设置预算上限、收货地址白名单、最终付款确认、异常订单拦截和完整审计日志；测试阶段使用隔离账户和低额度支付方式，不要把“可调用”理解为“可无人监管”。

GitHub 将 Copilot 代开的 PR 纳入 REST 与 GraphQL 的 author 搜索结果

A 级GitHub Copilot24小时高可信｜官方确认

重点事件：GitHub 于 7 月 16 日把此前已在 github.com 与 GitHub Mobile 生效的规则扩展至 REST API 和 GraphQL API：使用 `author:[username]` 或 `author:@me` 查询时，会同时返回用户本人创建以及 Copilot cloud agent 代表该用户创建的拉取请求。新全局 PR 面板会以“username with Copilot”标注责任主体。

为什么值得关注：依赖 GitHub API 统计个人产出、待审 PR 或自动分派的内部工具，结果集会在不改查询语句的情况下扩大。如果系统把 author 等同于人工提交者，可能导致绩效、审计和自动化规则误判。

落地建议：立即回归测试所有基于 author 的 REST/GraphQL 查询；在报表和审批中单独识别 Copilot 代开 PR，并用提交者标识、事件日志或标签区分人工与 Agent 行为。不要继续使用多条复杂查询重复合并同一责任人的 PR。

NotebookLM 更名为 Gemini Notebook，现有链接自动跳转

B 级Google 产品24小时高可信｜官方确认

重点事件：Google 于 7 月 16 日宣布将 NotebookLM 更名为 Gemini Notebook。产品仍作为独立研究工具运行，名称与 Logo 将在多个界面分批更新；快速发布和计划发布域均从 7 月 16 日开始扩展上线，功能可见时间可能超过 15 天。既有共享笔记本和用户链接会自动重定向，移动端部分用户需要更新应用。

为什么值得关注：这不是单纯视觉改名，而是 Google 把研究型知识产品进一步并入 Gemini 品牌体系的信号。企业内部文档、培训材料、资产清单和访问控制仍可能继续使用旧名称，造成支持与审计混乱。

落地建议：管理员无需迁移链接，但应同步更新内部产品目录、使用指南、白名单和培训材料；在灰度期同时支持 NotebookLM 与 Gemini Notebook 两个关键词，并提醒移动端用户检查版本，而不要把未出现新名称误判为账号异常。

NVIDIA 发布 Nemotron 3 Embed 开放模型，覆盖 Agent 检索与企业 RAG

A 级开源模型与检索24小时高可信｜官方模型团队发布

重点事件：NVIDIA 于 7 月 16 日发布 Nemotron 3 Embed 系列，包括 8B BF16、1B BF16 和面向 Blackwell 的 1B NVFP4 三个开放且可商业使用的嵌入模型。8B 版本在当日 RTEB 多语言检索榜单排名第一；系列支持 32k 上下文、多语言与代码检索，并开放微调、蒸馏配方以及 NIM 部署路径。

为什么值得关注：Agent 的总体质量经常受检索噪声、重复查询和长上下文截断限制。新的嵌入模型把竞争焦点从生成模型本身扩展到 Agent 记忆、代码检索与企业知识库的基础组件，同时提供 1B 低成本和 8B 高精度选择。

落地建议：不要只按公开榜单替换现有向量模型。应在自己的文档、代码仓库和多语言数据上比较 Recall@K、NDCG、P95 延迟、显存、索引重建成本与误召回，并为高风险知识库保留人工验证和回滚方案。

Claude 在印度开始显示卢比本地定价，但 UPI 与覆盖范围仍未完善

B 级价格与地区差异近7天补充社区多端验证，待官方确认

重点事件：7 月 13 日，多端观察显示部分印度用户在 Claude 网页与移动端看到卢比定价，旧状态是以美元计价并承担换汇摩擦。新价格包括：Claude Pro 年付折算每月 ₹2,000，对照美国年付每月 17 美元；Max 起价 ₹11,999/月，对照美国 100 美元/月；Team 起价 ₹2,399/席位/月，对照美国 20 美元/月。印度价格含本地税费，移动端价格略有差异，当前仍不支持 UPI，只能使用银行卡或应用商店支付。Anthropic 尚未公开确认完整灰度范围。

为什么值得关注：本地货币显示并不必然意味着更便宜，也不等同于本地支付链路已经完善。对跨地区采购团队而言，税费、应用商店加价、支付方式和账号灰度会造成实际成本差异。

落地建议：印度团队应分别核对网页、iOS、Android 和企业席位的最终含税价格，再决定购买渠道；财务系统应保存发现日期、账号范围和付款凭证。未看到卢比入口的账号不要通过地区切换规避限制，等待官方扩大覆盖。

  1. AI 入口竞争正在由模型能力转向操作系统、搜索数据和第三方应用权限，平台开放规则会直接重塑助手分发。

  4. 企业 AI 的性能瓶颈正下沉到检索与开发流程治理，嵌入模型选择和 Agent 生成代码的责任标识需要纳入工程规范。
