Apple在中国大陆Mac开放Qwen接入Siri与Writing Tools

S 级中国AI生态T0｜24小时高可信｜Apple指南经Reuters核验

重点事件：Apple发布面向符合条件的中国大陆Mac用户的指南，允许在macOS 26.6及以上版本中主动启用Qwen扩展，并将其接入Siri和Writing Tools。用户需登录Qwen账号；Apple指南称提交给Qwen的相关材料不能被阿里用于训练或改进模型。当前公开指南覆盖Mac，未说明具体由哪一个Qwen模型提供服务。

为什么值得关注：这是从“中国版Apple Intelligence合作预期”进入Mac端实际可用的独立阶段，Qwen获得系统级入口，Apple也获得一条本地合规的生成式AI落地路径。

落地建议：中国大陆Mac用户可先核对系统版本和账号条件；企业IT应先评估Qwen账号、数据边界、员工使用规范和终端版本，再决定是否统一开启。

Qwen Code v0.21.8发布：修复工作区信任继承安全问题

A 级AI编程T0｜官方稳定版官方确认｜Qwen GitHub Release

重点事件：Qwen Code于8月9日北京时间发布v0.21.8稳定版。官方Release明确修复“显式不信任工作区错误继承父目录信任”的安全问题，同时恢复fork PR实时autofix，新增OpenAI、Gemini与Vertex AI压缩缓存共享，优化/review，并让ACP Agent工具调用按配置并发执行。

为什么值得关注：这是直接影响本地代码访问边界和自动化审查行为的正式版本更新，不是普通UI改动；工作区信任错误可能让原本应被限制的目录获得不正确权限。

落地建议：正在使用Qwen Code的团队优先升级并回归测试workspace trust、符号链接、fork PR、MCP和CI review流程；受控开发环境应重新验证不信任目录确实被拒绝。

新增进展：OpenAI Atlas进入官方停止服务日

A 级产品退役T0｜今日节点官方确认｜OpenAI Help Center

重点事件：OpenAI此前已宣布退役Atlas；今天是官方列出的2026年8月9日停止服务日期。官方说明称，Atlas在该日期后可能无法打开、浏览或继续支持基于浏览器的Agent工作流，书签、打开的标签页和浏览历史不会自动迁移，Agent浏览能力转向ChatGPT桌面应用、Chrome扩展/侧栏及Codex等入口。

为什么值得关注：7月13日日报收录的是“退役宣布”，今天是从预告进入实际退役节点的新增阶段。继续依赖Atlas的个人和企业已经进入迁移窗口末端。

落地建议：仍有Atlas数据的用户应立即导出书签、保存关键URL并按敏感数据处理Cookie/会话文件；企业管理员同步清理内部文档、培训材料和自动化脚本中的Atlas依赖。

Nvidia拟向Stargate电力基础设施商Lancium投资最高30亿美元

A 级算力基础设施T0｜24小时中高可信｜Reuters转引The Information，双方未确认

重点事件：据The Information并由Reuters报道，Nvidia拟先投入20亿美元取得Lancium约20%股权，若电网接入等条件达成可追加10亿美元。Lancium拥有得州Abilene的Stargate首个运营园区所需土地与电力连接；报道给出的企业价值约100亿美元。Nvidia与Lancium截至Reuters发稿未回应置评。

为什么值得关注：GPU厂商的资本正在从芯片供应进一步下沉到土地、电力并网和数据中心开发，说明“可获得的兆瓦”正在成为与芯片本身同等稀缺的AI基础设施资源。

落地建议：数据中心和算力采购项目应把电网接入里程碑、土地、电力合同与GPU交付绑定评估；本事件在公司正式确认前不应按已完成投资处理。

字节跳动训练超大模型，目标规模最高约10万亿参数

A 级国产前沿模型T1｜2至7天首次收录高可信｜Financial Times

重点事件：Financial Times报道，字节跳动正在预训练一款规模可能最高约10万亿参数的模型，目标接近Anthropic最前沿模型级别。项目仍处于预训练阶段，尚不是产品/API发布，也没有权重或许可证可用性。

为什么值得关注：中国前沿模型竞争继续向超大规模训练推进，但这一阶段最值得观察的是算力、数据、MoE效率和最终推理成本，而不是把“参数规模”直接等同于能力。

落地建议：企业无需据此调整现有模型采购；关注后续是否出现模型卡、API、权重、推理框架支持和商业条款，届时应按不同事件阶段分别评估。

Moonshot重组境内架构，为香港上市争取监管批准

B 级AI融资与上市T1｜2至7天首次收录高可信｜Financial Times

重点事件：Financial Times报道，Moonshot AI正在拆解离岸红筹架构，将中国境内实体改制为股份公司，并引入国家AI基金、全国社保基金及地方国资等投资者，以争取北京对潜在香港上市的批准；公司尚未确认明确IPO时间表。

为什么值得关注：前沿模型公司的融资方式正在从美元VC继续转向境内资本与公开市场，资本结构会反过来影响跨境持股、算力采购和商业化节奏。

落地建议：合作方与投资人应重点核对重组后的合同主体、知识产权归属、数据责任和跨境结算安排；在正式招股或监管批准前，不应把IPO视为确定事件。

Gemini CLI夜间版改变容量耗尽错误语义，自动化重试需留意

B 级Gemini CLIT0｜夜间预发布官方确认｜Google GitHub prerelease

重点事件：Google发布Gemini CLI v0.56.0-nightly.20260808.gcf22ac7e8预发布版，其中将“Capacity Exhaustion”重新分类为Terminal Error，并继续更新Caretaker自动分诊、评测与Cloud Run工作流。该版本明确为nightly prerelease，不代表稳定通道已生效。

为什么值得关注：错误语义改变会影响脚本是否继续重试、切换模型或直接失败，长任务和无人值守Agent尤其容易被这种细节影响可靠性。

落地建议：仅nightly用户需要立即检查；使用稳定版的团队先更新错误码映射测试，避免未来升级后把容量耗尽误当成可无限重试的瞬时故障。
