新增进展：Qwen Code v0.21.10正式发布，ACP推理强度与企业局域网Local Control进入稳定版

A 级AI编程 / CLIT0｜官方稳定版官方确认｜QwenLM GitHub

重点事件：Qwen Code于8月11日发布v0.21.10稳定版。官方Highlights新增ACP会话配置，可把reasoning effort从Default调到Max；修复长时间headless AutoFix因无进度输出导致的超时；Desktop Local Control现在可在已验证网络接口上支持企业局域网地址，并继续改善Web Shell大文件交互。

为什么值得关注：昨天日报收录的是v0.21.9；本次属于“发布新版本”的独立事件阶段，只记录v0.21.10新增内容。对企业AI编程而言，推理强度可控、长任务稳定性和局域网控制范围都直接影响可用性与治理。

落地建议：使用Qwen Code的团队可升级后分别验证ACP推理档位的成本/质量曲线、headless长任务、Local Control监听范围与插件权限；企业内网应继续限制可信接口和可访问网段。

新增进展：Claude Code v2.1.228修复TUI冻结、Windows Git发现与模型回退问题

A 级Claude Code / 稳定性T0｜官方稳定版官方确认｜Anthropic GitHub

重点事件：Anthropic于北京时间8月12日凌晨发布Claude Code v2.1.228。官方说明修复四类问题：少数内部布局错误后交互界面停止重绘但进程仍运行；Windows从Git安装目录父目录启动时找不到git/Git Bash；执行/model后再进入/tui会回退到旧模型；安装或升级后的首个会话可能没有跨会话消息inbox。

为什么值得关注：这是继昨日v2.1.227后的新稳定版，属于新版本/修复阶段。前三项会直接造成“任务还在跑但界面像卡死”“Windows命令链不可用”“实际模型与用户选择不一致”等生产体验问题。

落地建议：Windows、跨会话协作或经常切换模型的团队优先升级到2.1.228，并回归测试Git Bash发现、/model→/tui状态保持以及升级后的首会话消息通道。

IBM与Together AI签2.4亿美元多年协议：约2000颗Blackwell 300先落地推理集群

A 级推理基础设施 / 开放模型T0｜24小时高可信｜Reuters

重点事件：IBM与Together AI签署价值2.4亿美元的多年协议，在IBM Cloud建设Nvidia驱动的AI推理集群。首批部署约2000颗Blackwell 300芯片，采用HGX B300与Spectrum-X网络，落地美国，面向DeepSeek、MiniMax、Kimi等开放模型的训练与推理服务；Together AI称容量预计会提前2至3个月售罄。

为什么值得关注：开放模型竞争不再只看权重和API价格，正在进入“谁能拿到稳定推理容量、把集群交付给企业”的基础设施阶段。对中国开放模型而言，这也是进入海外企业工作负载的直接渠道。

落地建议：企业若评估开放模型托管，可把Together/IBM与自建GPU云、OpenRouter等方案做TCO比较，重点核对模型许可证、数据驻留、吞吐、延迟、保留容量与退出成本。

新增进展：Manus恢复独立运营，Meta分离流程开始删除部分用户数据

A 级Agent / 公司结构T0｜24小时高可信｜Reuters

重点事件：Manus于8月11日表示将恢复作为独立公司运营，并在与Meta分离过程中删除部分用户数据。这不是此前“交易被要求拆分”或“运营隔离”的重复报道，而是从拆分安排进入独立运营与数据处置的新增阶段。

为什么值得关注：Agent产品的控制权、数据归属和账户连续性会直接影响企业采购。Manus案例说明跨境并购/拆分不仅是资本事件，还可能改变数据生命周期、合同主体、服务连续性与企业集成边界。

落地建议：正在使用Manus或类似外部Agent的企业应检查数据导出/删除政策、API与账户迁移、DPA/合同主体及关键流程替代方案；不要把单一Agent平台绑定为不可替换的核心执行层。

Gemini CLI v0.56.0-preview.1修复“假容量耗尽”和MCP OAuth刷新，配额判断进入新预览版

A 级Gemini CLI / 配额T0｜官方预览版官方确认｜Google GitHub

重点事件：Google发布Gemini CLI v0.56.0-preview.1。变更包括将Capacity Exhaustion重新分类为终止错误，修复“误判模型容量耗尽”及核心配额查询的模型映射，并修复MCP OAuth令牌刷新时使用已保存client ID的问题；同时推进Caretaker Agent的自动化triage/eval能力。

为什么值得关注：配额错误会让用户把客户端判断误认为服务端真实限额；MCP OAuth刷新问题则会直接中断长会话工具链。虽然这是preview而非稳定版，但属于官方确认且可直接验证的CLI行为变化。

落地建议：经常遇到capacity exhausted、MCP重新登录或自动化Issue处理的开发者可在隔离环境试用preview；生产环境仍建议等待稳定版或锁定版本，并对真实服务端配额单独监控。

CoreWeave把2026资本开支上调至350亿—390亿美元，近端AI算力容量已基本售罄

A 级Neocloud / 算力T0｜24小时高可信｜Reuters

重点事件：CoreWeave二季度收入26亿美元附近并上调全年目标，同时把2026年资本开支区间从310亿—350亿美元提高到350亿—390亿美元；收入积压升至1042亿美元，本季度迄今新增客户承诺超过250亿美元。管理层称近端容量实际上已经售罄。

为什么值得关注：这比单纯的财报增长更具行动价值：AI云需求仍在强迫neocloud继续前置购芯、建机房和锁电力，且融资与交付能力已成为与GPU本身同等重要的约束。

落地建议：GPU云、IDC、电力与液冷供应商可据此调整2027产能判断；采购方应提前锁定容量并审查长期承诺、价格锁定、迁移成本与供应商杠杆水平。

Supermicro给出650亿—720亿美元FY2027收入指引，AI服务器客户集中度继续抬升

B 级AI服务器 / 企业硬件T0｜24小时高可信｜WSJ + 公司IR

重点事件：Supermicro预计2027财年收入650亿至720亿美元，高于市场平均预期约525亿美元；第四财季收入111.2亿美元、毛利率17.5%。公司披露2026财年有9个客户年度收入贡献超过10亿美元，而上一年为4个。

为什么值得关注：AI基础设施需求仍在向整机、机柜和数据中心集成商扩散，但大客户数量和单客规模同步抬升，意味着供应链放量与客户集中风险同时增加。

落地建议：做AI服务器、机柜、电源、液冷或制造供应链的团队可把Supermicro指引作为需求领先信号；企业采购则要关注交付延期、集中采购议价和多供应商冗余。

Fermi拿下TensorWave作为Texas Project Matador首个AI租户，15年租约验证超大园区需求

B 级数据中心 / AI云T0｜24小时高可信｜WSJ + Barron's

重点事件：Fermi宣布AI云公司TensorWave成为其Texas Project Matador的首个租户。WSJ报道该消息推动Fermi股价显著上涨；Barron's披露该15年租约价值约65亿美元，规划分阶段入住，并带有继续扩容至650MW以上的权利。

为什么值得关注：在大型AI园区普遍面临“先拿电、再找租户”的融资压力下，首个长期租户是把规划项目变成可融资资产的关键节点，也能反向拉动GPU、网络、电力与施工订单。

落地建议：关注数据中心项目时，应从“宣布多少GW”切换到“签了谁、租多久、何时交付、是否有扩容权、融资是否落地”。对于供应链公司，首租户通常比总规划容量更有订单判断价值。

今日趋势判断

  1. AI编程工具进入“高频小步快跑”阶段：Qwen Code与Claude Code连续两天发布稳定版，Gemini CLI也通过preview处理配额与MCP问题。选型不能只看模型能力，还要看客户端更新质量、回归机制和版本锁定能力。
  2. 开放模型的商业战场正在从API价格走向推理容量：IBM + Together AI直接配置Blackwell 300集群，说明开放模型能否进入企业，越来越依赖稳定算力、网络、数据驻留和SLA。
  3. 算力扩张仍由“已售容量”推动：CoreWeave近端容量售罄并继续提高资本开支，Supermicro和TensorWave/Fermi也提供了服务器与园区侧的需求验证，但高杠杆、交付和客户集中风险同步上升。

选题价值 / 落地建议 / 商业机会

  • 选题价值：可重点做“为什么AI编程工具一周多次发版”“开放模型正在争夺Blackwell推理集群”“超大AI园区真正的关键不是GW，而是首租户与长期合同”。
