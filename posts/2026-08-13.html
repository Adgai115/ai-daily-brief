新增进展：Claude Code v2.1.229强化长思考连接、Remote Control与自托管Runner

A 级Claude Code / 企业AgentT0｜官方稳定版官方确认｜Anthropic GitHub

重点事件：Anthropic于北京时间8月13日凌晨发布Claude Code v2.1.229。新增自托管Runner的服务端Hook支持；Gateway流式响应在长思考停顿期间加入SSE keepalive，降低Vertex与Bedrock上游空闲超时；同时修复长响应流式输出部分消失/重复、Windows UNC路径崩溃、MCP OAuth严格授权服务器兼容、自托管Runner凭证提示卡死等问题。

为什么值得关注：这是昨日v2.1.228后的独立新版本阶段，新增内容直接影响企业网关、云模型路由、自托管执行器与Remote Control稳定性，而不是普通界面微调。

落地建议：使用Bedrock、Vertex、自托管Runner或Remote Control的团队优先升级并回归测试长思考连接、MCP OAuth、Windows路径、Runner Git凭证与流式输出；生产环境继续锁定版本并保留回滚。

新增进展：Nvidia GPU融资披露25%残值支持，芯片租赁正在形成新资产类别

A 级GPU融资 / 基础设施T0｜新增结构披露高可信｜Financial Times

重点事件：在昨日“超5000亿美元第三方算力融资平台”之后，Financial Times进一步披露交易结构：Nvidia将支持部分GPU租赁在租期内至少保有约25%的残值，若价值低于约定水平，公司承担前段损失；参与机构正在研究把GPU租赁债权进一步证券化。

为什么值得关注：新增信息不是融资规模重复，而是风险如何分配。GPU从采购品进一步变成可抵押、可租赁、可证券化的金融资产，设备残值与软件延寿能力开始直接决定AI项目融资成本。

落地建议：GPU云、数据中心和大型算力采购方应把设备残值、租期、再营销渠道、技术迭代和担保方责任纳入TCO；融资方案不应只比较利率，还要测试模型效率提升导致旧GPU需求下降的情景。

Bank of America推出2500亿美元关键基础设施融资计划，数据中心与计算列入核心方向

A 级AI基础设施 / 融资T0｜24小时高可信｜Reuters

重点事件：Bank of America宣布“Critical Infrastructure Finance Initiative”，计划在2027年7月前部署2500亿美元，覆盖数字基础设施（包括数据中心与计算）、能源与电力、交通及天然气等领域，工具包括贷款、投资、资本市场服务和顾问业务。

为什么值得关注：该2500亿美元并非全部用于AI，但AI数据中心明确处于目标范围。大型银行正把AI算力、电力和基础设施视为可规模化配置的融资类别，资本供给继续从科技股权向项目融资扩散。

落地建议：数据中心、储能、电力与算力项目方应提前准备可融资性材料：并网许可、客户合同、设备残值、建设里程碑和社区风险；制造业服务商可关注配电、冷却、网络和运维配套订单。

Cerebras上调全年收入与毛利指引，云收入已同比约四倍增长

A 级AI芯片 / 推理云T0｜24小时高可信｜Reuters

重点事件：Cerebras二季度收入1.8011亿美元，同比增长74.3%，但低于市场预期；其云业务收入升至1.26亿美元、约为上年同期四倍。公司把2026年调整后收入指引从8.55亿—8.65亿美元上调至8.80亿—8.90亿美元，并把全年调整后毛利率指引上调至41%—43%。

为什么值得关注：更重要的信号不是股价波动，而是Cerebras正在从硬件销售向云推理收入倾斜；其片上内存与TSMC 5nm路线也使其受HBM和先进节点紧张影响不同于GPU厂商。

落地建议：企业评估非GPU推理方案时，应同时比较云端吞吐、模型兼容、单token成本、供应可得性与退出成本；不要只根据芯片峰值性能判断替代价值。

Nebius四个AI云大单平均超10亿美元，把2026签约电力目标提高到5GW

A 级Neocloud / 算力T0｜24小时高可信｜Reuters

重点事件：Nebius二季度收入5.823亿美元并超过预期，核心AI云收入同比接近六倍；公司签下4个平均金额超过10亿美元的AI云合同，客户承诺总额超过400亿美元，并把2026年签约电力目标从“超过4GW”提高到5GW，计划自2027年起每年部署超过1GW容量。

为什么值得关注：这是一条独立于昨日CoreWeave的供给侧变化：Neocloud竞争正在从GPU数量转向“可签约电力+预付款+长期容量”。客户愿意通过大额预付款锁算力，说明近端容量仍具有议价权。

落地建议：采购AI云的企业应把合同预付款、容量上线日期、跨区域迁移和供应商信用风险纳入评估；数据中心项目方应把兆瓦级价格与客户合同质量联动测算。

Foxconn AI服务器相关业务跨过收入半壁江山，Vera Rubin机架Q4启动出货
