一、价格 / 限流 / 可用性雷达

1. DeepSeek 官方价格页：V4-Pro 当前仍是重点监控对象

S 级价格雷达官方来源

重点事件：DeepSeek 官方 API 价格页显示，当前模型为 deepseek-v4-flash 与 deepseek-v4-pro，均支持 1M 上下文、最大 384K 输出；V4-Pro 当前价格为 cache hit input $0.003625 / 1M tokens、cache miss input $0.435 / 1M tokens、output $0.87 / 1M tokens；V4-Flash 为 cache hit input $0.0028、cache miss input $0.14、output $0.28。

新增关键点：deepseek-chat 与 deepseek-reasoner 将在 2026-07-24 15:59 UTC 废弃，分别对应 deepseek-v4-flash 的非思考与思考模式。

为什么值得关注：这类价格与模型名废弃信息不会总被媒体报道，但会直接影响 API 接入、OpenClaw/LingTai Agent 配置、模型路由和成本预算。

行动建议：立即把 DeepSeek 配置从 deepseek-chat / deepseek-reasoner 迁移到 deepseek-v4-flash / deepseek-v4-pro；成本策略上默认 Flash，复杂推理再走 Pro。

2. DeepSeek 状态页：当前正常，但历史上充值与资源约束风险真实存在

A 级可用性官方 + 权威媒体

重点事件：DeepSeek 状态页当前显示“Everything is running smoothly”，API 服务近 3 个月 uptime 为 99.88%，网页对话服务为 99.89%。但 Reuters 曾报道 DeepSeek 因高流量和服务器资源限制暂停 API top-up 充值。

为什么值得关注：便宜模型不等于稳定供应。对于企业 Agent，价格、充值、并发、状态页都要纳入选型。

行动建议：日报每天保留 DeepSeek 状态检查；LingTai Agent 中为 DeepSeek 增加 provider health check，异常时自动切换 Qwen / GLM / OpenRouter 备选。

3. DeepSeek V4-Pro 永久降价背景：低价不是短期促销，而是架构变量

S 级价格/国产模型权威媒体

重点事件：Reuters 5 月报道，DeepSeek 将 V4-Pro 75% 降价变为永久价格，API 成本从 0.1–24 元 / 百万 token 降至 0.025–6 元 / 百万 token。

为什么值得关注：这是企业 Agent 多模型架构的价格锚点：国产模型不是备胎，而可能成为日常主力模型。

行动建议：把 DeepSeek 放入默认低成本通道；在复杂任务、长上下文、代码任务上建立实际 benchmark，再决定是否替换部分 OpenAI / Claude 调用。

二、今日必看

5. AI 成本飙升，企业开始主动选择更便宜的小模型与开源模型

S 级价格/成本权威媒体

重点事件：Reuters 报道，企业 AI 支出从固定订阅转向 token 用量计费后，Uber 等公司出现预算快速消耗；OpenRouter 等路由平台受益，开源模型在其 token 处理中占比达到 65%。

为什么值得关注：企业 Agent 的架构选择将从“最强模型优先”转向“任务价值、成本、稳定性、合规”联合路由。

行动建议：LingTai Agent 必须把模型路由、预算、provider health、调用日志做成基础模块。

六、风险 / 政策 / 价格 / 安全

17. Claude Code 类 Agent 可被“干净仓库”诱导安装恶意代码

S 级安全行业媒体

重点事件：Tom’s Hardware 报道 Mozilla 0din 团队演示：AI coding agent 可能被看似正常的 GitHub 仓库诱导执行恶意初始化脚本。

为什么值得关注：Agent 的风险不只是写错代码，而是能执行命令、读文件、装依赖、拿密钥。

行动建议：Claude Code/Codex/OpenClaw 使用时默认开启沙箱、命令白名单、未知仓库只读预检、密钥隔离和执行日志。

Tom’s Hardware 来源

今日趋势判断

  • 价格、限流、充值和服务状态已经成为 AI Agent 选型的一等指标。
  • DeepSeek 的价格页与状态页应每天固定监控，尤其是模型名废弃、V4-Pro 价格、充值状态和服务稳定性。
  • AI 编程工具正在从体验竞争转向组织计费、额度治理、供应链安全和任务审计。
  • 中文模型不只是低价替代，而是企业 Agent 国产化、多模型路由和成本控制的重要组成。

价格/限流监控结果

  • DeepSeek：官方价格页确认 V4-Flash / V4-Pro 价格、1M 上下文、384K 最大输出、并发限制；状态页当前正常。
  • DeepSeek 迁移提醒：deepseek-chat / deepseek-reasoner 将于 2026-07-24 废弃，应提前替换。
  • Qwen / GLM / Kimi / 豆包 / MiniMax：本轮未确认 2026-06-30 当天官方涨价或限流公告，但已纳入每日硬性监控。
  • Codex / Copilot / Gemini / Claude：额度异常、消费计费、算力限制、服务故障均显示可用性风险正在上升。

对用户项目的启发

  • LingTai Agent：优先做 provider health check、模型路由、成本预算、fallback 和每任务成本日志。
  • OpenClaw / Feishu Agent：DeepSeek 这类低价模型适合日报、摘要、知识检索；复杂代码/长任务再切换强模型。
  • 企业软件 / 制造业方案：AI Agent 方案中要加入“多模型可替换 + 成本上限 + 审计日志 + 服务降级”。
