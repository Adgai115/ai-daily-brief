# AI热点日报

用于托管每日 AI 热点 HTML 日报。

## 目录结构

```text
/
├── index.html
├── archive.html
├── posts/
│   └── 2026-06-25.html
└── README.md
```

## GitHub Pages

启用方式：

1. 打开仓库 `Settings`。
2. 进入 `Pages`。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub Pages 构建完成。

启用后访问：

```text
https://adgai115.github.io/ai-daily-brief/
```

日报页面示例：

```text
https://adgai115.github.io/ai-daily-brief/posts/2026-06-25.html
```
